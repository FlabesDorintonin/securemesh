# SecureMesh Commander v1.0.4 Operator

Операторский offline Commander для firmware v1.0.4. В обычном интерфейсе используются только понятные состояния: связь, основной/запасной путь, готовность, проверка исправности, радар устройств и журнал. Внутренние метрики и названия wire-протокола не выводятся оператору.

Windows: `START_COMMANDER.bat`. Вручную: `python serve.py`, затем открыть `http://localhost:8765` в Chrome/Edge.

Основные экраны: Сеть, Схема сети, Пути связи, Проверка резерва, Проверка связи, Учебная схема, Радар устройств, Журнал.

Карточки узлов: имя и закрепление сохраняются; отключённый узел можно переподключить или убрать из текущей сессии без потери имени.

Инженерный BLE-контракт остаётся application v2 / fragment v1 и описан отдельно в `APP_TEST_PANEL_PROTOCOL.md`.
